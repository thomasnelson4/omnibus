# Reference projects

implementation and design reference. When a task asks to reference one of them,
inspect its local source checkout.

| Project | Local path (relative to this repository) | Upstream |
| --- | --- | --- |
| Kapowarr | `../omnibus-references/kapowarr/` | https://github.com/Casvt/Kapowarr |
| Shelfmark | `../omnibus-references/shelfmark/` | https://github.com/calibrain/shelfmark |
| Komga | `../omnibus-references/komga/` | https://github.com/gotson/komga |

The reference checkouts live outside this repository so their source files are
excluded from Omnibus's TypeScript compilation and Docker build context.
